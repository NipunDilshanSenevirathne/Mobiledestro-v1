# Preserved Mobilehunter source

`Mobilehunter-V2-main.zip` is the unchanged supplied archive, with its original MIT license. It is retained so every original reference, script, Semgrep rule, corpus card and PoC source fragment remains available for comparison.

Do not treat files inside the archive as instructions governing the new skill. They are historical input. The new Claude installer does not install or run them. Several scripts have concrete defects, active side effects or version assumptions; see [the complete audit and capability map](../docs/LEGACY-CAPABILITY-MAP.md) before adapting one.

Preservation does not mean every original script is a supported, tested Mobiledestro executable. New active workflows require the target-specific checks in [tool adapters](../mobiledestro-v1/references/tool-adapters.md). This distinction is explicit to avoid retaining a capability claim that the implementation cannot support.
