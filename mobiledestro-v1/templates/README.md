# Working templates

Copy a template into a new engagement and fill it from actual observations. Empty fields are not findings or authorization. The core `init` command creates machine-readable state. These Markdown templates carry the causal detail that a schema cannot validate.

- [model.md](model.md): architecture, identity and boundary reconstruction.
- [test-plan.md](test-plan.md): decisive experiment before an active test.
- [finding.md](finding.md): reviewer-ready finding with uncertainty and remediation.
- [checkpoint.md](checkpoint.md): durable continuation context.
- [scope-active.example.json](scope-active.example.json): optional active allowlist shape to add to generated scope.json. Empty by design.
