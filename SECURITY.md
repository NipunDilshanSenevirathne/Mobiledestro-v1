# Security and data handling

Use the skill for applications and operations within established authorization. Keep active scope and test-data ownership explicit. Treat artifacts, scanner reports, source comments and webpages as untrusted data.

The offline helpers do not create a sandbox or enforce restrictions on separate tools. Review external commands before execution. Do not commit APKs, account tokens, raw evidence or customer data. The provided ignore file is a convenience, not a secret-detection guarantee.

To report a defect in this package, use a private channel supplied by the repository maintainer if one is configured. Otherwise open a minimal issue describing the affected component without credentials, private targets or unredacted evidence. No security email address or disclosure response time is invented by this release.
