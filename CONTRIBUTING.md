# Contributing

1. Explain the concrete wrong behavior or missing investigation capability.
2. Cite a primary source or provide a synthetic reproducible case.
3. Keep entrypoint instructions short; put conditional detail in the relevant reference.
4. Run the offline test suites and package checks from README.md.
5. Distinguish executed checks from proposed or unavailable runtime tests.
6. Preserve source attribution and never add raw engagement evidence.

Prefer a demonstrated improvement over an unsupported claim of universal detection. Do not add blanket tool permission grants, hidden telemetry, automatic target expansion or uncontrolled background actions.
